# GHOSTFRAME v0.6.3 – Ladder Hatch and Garage Door

- Clickable square and triangular ladder hatches under **Böden / Decken**; a matching floor frame is required.
- Garage door moved into the immediately visible **Wände / Öffnungen** catalog group. Clicking an existing edge installs a garage door into a wall frame.
- Distinct 2D markings for hatches and garage doors; no transparent floor block for open floor frames.
- 3D floor frames show real openings; installed hatches show a metal plate and ladder below. Garage doors have a wider framed opening and metal roller-panel segments.
- Floor insert is saved on the corresponding tile with version-compatible optional `floorInsert` property; existing v0.6.2 blueprints continue to load.
- Reference behavior, not a verified Rust patch-specific physics model.
